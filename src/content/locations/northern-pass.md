# Northern Pass

The northern pass is where the valley's protection thins: a gap in the ridges, a place a people might hold if they had to.

The Five hold it. Shadow-wolves and ichor-bears come first. Behind them, the Darkness gathers for the true assault.

This is not a place Thornhaven named for glory. It is a place they named because you have to call the door something.
